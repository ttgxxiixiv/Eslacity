# Eslacity: план

PWA для изучения испанского (A1 → B1) русскоязычным новичком. Город из 20 локаций, каждая локация это тематический набор слов. Отдельный трек грамматики.

## Стек

React 18 + Vite + TypeScript (strict), Tailwind, Zustand, Dexie (IndexedDB), vite-plugin-pwa (generateSW, precache всего бандла вместе с контентом), Vitest. Для скриптов `tsx`. Роутинг: react-router с hash-историей, чтобы PWA без сервера не ловила 404 на глубоких ссылках.

## Конфиг варианта языка

```ts
// src/config.ts
export type Variant = 'es-ES' | 'es-419';
export const VARIANT: Variant = 'es-ES';
export const VARIANTS = {
  'es-ES':  { voices: ['es-ES'], vosotros: true },
  'es-419': { voices: ['es-MX', 'es-US', 'es-419', 'es-AR', 'es-CO'], vosotros: false },
};
```

Слово по умолчанию хранит испанскую форму Испании. Если в Латинской Америке говорят иначе, в слове есть поле `latam` (el ordenador → la computadora, el zumo → el jugo, el móvil → el celular). Строки таблиц спряжения с vosotros помечены `region: 'es'` и в латиноамериканском режиме скрываются, а упражнения на vosotros пропускаются. Голос: сначала точное совпадение из списка, затем любой `es-*`, иначе кнопка звука скрыта.

## Схемы данных

### Слово

```ts
type LocationId = 'market' | 'cafe' | 'restaurant' | 'supermarket' | 'pharmacy'
  | 'hospital' | 'bank' | 'post' | 'station' | 'airport' | 'hotel' | 'school'
  | 'office' | 'clothes' | 'barber' | 'gym' | 'park' | 'beach' | 'police' | 'home';

type Pos = 'noun' | 'verb' | 'adj' | 'adv' | 'pron' | 'prep' | 'num' | 'interj' | 'phrase';
type Gender = 'm' | 'f';
type Cefr = 'A1' | 'A2' | 'B1';

interface Word {
  id: string;            // "cafe.cortado", уникален во всём контенте
  es: string;            // "el cortado"; у существительных артикль обязателен
  ru: string;            // "кофе с каплей молока"
  pos: Pos;
  gender?: Gender;       // обязателен для noun
  level: 1 | 2 | 3 | 4 | 5;  // уровень здания
  cefr: Cefr;
  example: { es: string; ru: string };
  alt?: string[];        // другие принимаемые ответы: ["el café solo"]
  latam?: string;        // форма для es-419, если отличается
  plural?: string;       // для неочевидных случаев: "los lápices"
}

interface LocationWords {
  location: LocationId;
  words: Word[];
}
```

Существительные женского рода с ударным a- (el agua, el aula) пишутся с `el`, а `gender: 'f'`. Валидатор это знает.

### Локация

```ts
interface LocationMeta {
  id: LocationId;
  ru: string;            // "Кафе"
  emoji: string;         // "☕"
  unlockCost: number;    // 0 для кафе
  order: number;         // позиция в сетке
}
```

### Урок грамматики

```ts
type District = 'A1' | 'A2' | 'B1.1' | 'B1.2';

type TheoryBlock =
  | { kind: 'text'; md: string }                 // короткий абзац, **жирный** допускается
  | { kind: 'table'; caption?: string; head: string[];
      rows: { cells: string[]; region?: 'es' }[] }
  | { kind: 'tip'; md: string };                 // "Запомни" / частая ошибка

type GrammarExercise =
  | { kind: 'choose'; prompt: string; ru?: string; options: string[]; answer: number; explain: string }
  | { kind: 'gap'; sentence: string; ru: string; options: string[]; answer: number; explain: string } // "Yo ___ de Rusia."
  | { kind: 'truefalse'; statement: string; ru?: string; answer: boolean; explain: string };

interface GrammarLesson {
  id: string;            // "a1.05-ser-estar"
  district: District;
  order: number;
  title: string;
  theory: TheoryBlock[];
  examples: { es: string; ru: string }[];   // 3-5, с озвучкой
  exercises: GrammarExercise[];             // 6: по 2 каждого типа
  region?: 'es';         // урок только для es-ES (vosotros)
}
```

### Прогресс в IndexedDB (Dexie)

```ts
cards:     { wordId (pk), ef, interval, reps, due (index), lapses, learnedAt, lastReviewedAt }
buildings: { locationId (pk), level (0 = закрыто), lastCollectedAt }
grammar:   { lessonId (pk), completedAt, bestScore }
days:      { date (pk, 'YYYY-MM-DD'), xp, newWords, reviews, lessons, grammarLessons, goalMet }
meta:      { key (pk), value }   // coins, streak, freezes, settings, achievements, weekly
```

Zustand держит копию в памяти. Интерфейс меняется синхронно из стора, запись в Dexie и озвучка уходят в `requestAnimationFrame` → `setTimeout(0)`, то есть после отрисовки кадра с ответом.

## Экраны

1. Город (главный). Сетка 4×5 с эмодзи. Закрытое здание серое с ценой, открытое показывает уровень и монеты, накопленные пассивно. Сверху: монеты, стрик, полоска дневной цели. Крупная кнопка «Повторить (N)».
2. Локация. Уровни 1-5, слова текущего уровня (тап озвучивает), кнопки «Учить» и «Улучшить за X».
3. Урок. Прогресс-бар, упражнение, нижняя панель с результатом («Верно», «Почти: правильно está», «Неверно»).
4. Итог урока. XP, монеты, слова с ошибками.
5. Повторение. Тот же плеер упражнений, источник: карточки с due ≤ сейчас, до 20 за сессию.
6. Блиц. 60 секунд, выбор из 4, счёт и рекорд.
7. Грамматика. 4 района, A1 открыт, остальные с пометкой «скоро». Внутри список уроков.
8. Урок грамматики. Теория с таблицей → примеры с озвучкой → 6 упражнений в одно касание.
9. Словарь. Все выученные слова, поиск, статус SRS (когда следующее повторение).
10. Профиль. Стрик и заморозки, недельный челлендж, достижения, статистика за 7 дней.
11. Настройки. Дневная цель 50/100/150/250, скорость речи, проверка голоса, экспорт и импорт прогресса в JSON (замена аккаунту), сброс.

Нижняя навигация: Город, Грамматика, Повтор, Профиль.

## Как устроено обучение слов

Открытие здания даёт уровень 1: 10-12 слов. Слова уровня разбиты на 2 урока по 5-6 слов. Урок: карточка знакомства со словом (слово, перевод, пример, звук), потом 12-16 упражнений по этим словам в порядке от лёгких к трудным: выбор es→ru, выбор ru→es, пары, буквы, фраза, ввод. Ошибка возвращает это слово в конец очереди другим типом упражнения. Первая попытка по каждому слову выставляет ему оценку SM-2 и заводит карточку.

Когда все слова уровня заведены в SRS, открывается кнопка «Улучшить» (нужны монеты). Уровни 1-2 это A1, 3-4 A2, 5 B1.

Упражнения:

1. Выбор из 4 в обе стороны. Дистракторы из той же локации и той же части речи, для существительных того же рода, чтобы нельзя было угадать по артиклю.
2. Буквы. Сверху переключатель el/la, ниже перемешанные буквы слова. Ответ засчитывается только с правильным артиклем.
3. Пары. 5 пар, неверная пара мигает красным, верные гаснут.
4. Фраза. Пример слова разбит на токены, плюс 1-2 лишних слова с уровня A2 и выше.
5. Ввод. Правила проверки ниже.
6. Блиц. Отдельный режим с экрана города, берёт уже выученные слова (нужно минимум 8). На SRS не влияет, чтобы угадывание на скорость не портило интервалы.

Проверка ввода (`domain/answer.ts`):

- нормализация: нижний регистр, trim, схлопывание пробелов, удаление ¿ ¡ ? ! . ,
- точное совпадение с `es` или одним из `alt` → верно
- совпадение после снятия ударений (á→a, é→e, í→i, ó→o, ú→u, ü→u) → почти
- расстояние Левенштейна 1 до любого допустимого ответа → почти
- нет артикля или не тот артикль → неверно с подсказкой «el cortado, мужской род». Раз артикль часть ответа, «почти» тут поощрял бы как раз ту ошибку, которую мы хотим отучить делать.

«Почти» считается верным ответом для урока, но в SM-2 идёт с оценкой 3.

SRS (SM-2): оценки 5 = верно с первой попытки во вводе, 4 = верно в выборе, 3 = почти, 1 = неверно. При оценке меньше 3 reps = 0, interval = 1 день. EF не опускается ниже 1.3. Due хранится как timestamp начала дня, чтобы «на сегодня» не зависело от времени суток.

## Экономика

Числа в `config.ts`, подкручиваются без правки логики.

- Верный ответ: +1 монета, +10 XP (почти: +1 монета, +5 XP). Итог урока: +15 монет. Повторение: +1 монета за карточку.
- Кафе открыто сразу. Цены открытия остальных: от 60 до 600 по мере порядка в сетке.
- Улучшение до уровня n: `unlockCost × n × 0.8`, минимум 40.
- Пассивный доход: `2 × уровень` монет в час с каждого здания. Копится по каждому зданию с `lastCollectedAt`, не больше 8 часов. Сбор тапом по значку монеты на здании.
- Заморозка стрика: 150 монет, храним максимум 2. Пропущенный день тратит одну автоматически при следующем запуске.

## Мотивация

- Дневная цель 50/100/150/250 XP, по умолчанию 100.
- Стрик растёт, если за день выполнена цель.
- Недельный челлендж выбирается детерминированно по номеру ISO-недели из шаблонов: выучить 40 новых слов, сделать 150 повторений, пройти 5 уроков грамматики, выполнить цель 5 дней. Награда 200 монет.
- 18 достижений: первое слово, 50/200/500 слов, первое здание, 5/10/20 зданий, первое здание 5 уровня, стрик 3/7/30, 100 повторений за неделю, район A1 пройден, блиц 20+ за раунд, 10 ответов вводом подряд без ошибок, все здания открыты, первая заморозка.

Геймификация тихая: без конфетти и всплывающих окон посреди урока. Достижение показывается строкой на экране итогов.

## Контент и валидация

Контент пишу сам по схеме и прогоняю `npm run validate` после каждой порции. `npm run build` вызывает валидацию первой, так что сборка с кривым контентом не пройдёт.

Проверки валидатора:

- JSON соответствует схеме, обязательные поля не пустые
- дубли `id` во всём контенте, дубли `es` внутри локации
- существительное без el/la/los/las или с артиклем, не совпадающим с родом (с исключением для ударного a-)
- у не-существительных артикля быть не должно (кроме pos: phrase)
- пример содержит само слово (с учётом формы: предупреждение, не ошибка)
- в уровне 10-12 слов
- уроки грамматики: 3-5 примеров, индекс `answer` в пределах `options`, у каждого упражнения есть `explain`, в `gap` ровно один `___`

## Отзывчивость

- Обработчики ответов синхронно меняют стор и сразу рисуют результат. Звук и запись в Dexie после кадра.
- Контент локаций грузится лениво, но предзагружается при открытии экрана локации, так что урок стартует без ожидания.
- `touch-action: manipulation` и отказ от 300 мс задержки, кнопки реагируют на `pointerdown` визуально (`:active` через transform: scale).
- Анимации только `transform` и `opacity`, `prefers-reduced-motion` их отключает.

## Этапы

1. План (этот документ). Жду ОК.
2. MVP: каркас проекта, кафе с 3 уровнями (~33 слова), все 6 упражнений, SRS, сохранение прогресса, валидатор, тесты для answer.ts, srs.ts, lessonQueue.ts.
3. Город: сетка, монеты, открытие и улучшение, пассивный доход. Тесты для economy.ts.
4. Грамматика A1: все уроки, экраны. Валидатор расширяется на грамматику.
5. Мотивация (XP, цель, стрик, заморозки, челлендж, достижения), слова уровней 1-2 для остальных 19 локаций, PWA: манифест, иконки, precache, проверка офлайн. Тесты для streak.ts, goals.ts.

После каждого этапа: `npm run build` без ошибок, `npm test`, коммит и пуш в `claude/spanish-pwa-city-app-3oghmr`, отчёт с чек-листом для проверки на телефоне.
