# Дорожная карта Eslacity

Пошаговый план развития для работы через Claude Code. Что строим, описано в `docs/GAME.md`: путешествие героя к Хранилищу Эликсира знания через пять глав (A1–C1), обрывки карты, жители с миссиями и поручениями, медали от дерева до бриллианта, Сфинкс с загадками в финале. К финалу у игрока словарный запас не меньше 3000 слов на изучаемом языке (раздел «Словарный запас» в `GAME.md`). Язык в этой игре — инструмент: каждое игровое действие требует понять или сказать что-то на изучаемом языке.

Правила проекта, команды и порядок выпуска версии описаны в `CLAUDE.md`, Claude Code читает его сам.

## Как работать по этому плану

1. Одна задача — одна сессия Claude Code и одна версия приложения. Если задача не помещается, Claude сам предложит, где её разрезать.
2. Скопируйте в сессию запрос из блока «Запрос» у задачи. Подробности Claude прочитает здесь и в `docs/GAME.md`.
3. Идите по порядку. Зависимости указаны в строке «Нужно до».
4. После выпуска Claude отмечает задачу `[x]` в оглавлении и дописывает журнал в конце файла.
5. Если по ходу решение изменилось (формат данных, числа, названия), Claude правит следующие задачи здесь и `docs/GAME.md`, чтобы документы не расходились с кодом.

### Определение готовности (для каждой задачи)

- Логика в `src/domain/` покрыта тестами, `npm test` проходит.
- `npm run build` проходит: валидатор контента, типы, сборка.
- Сценарий задачи пройден в браузере на обоих языках (после 0.2 — через `npm run e2e`).
- Прогресс со старой версии открывается без потерь, ничего уже открытого не закрывается. Если менялась база, есть тест на перенос.
- Версия поднята, есть запись в `src/content/changelog.ts` и раздел в `docs/STAGES.md`.
- Изменения отправлены в ветку `claude/spanish-pwa-city-app-3oghmr`, деплой на GitHub Pages прошёл.

### Графика

Медали, портреты жителей, карта странствий, Сфинкс и Хранилище требуют рисунков. Порядок для таких задач: Claude делает рабочий вариант, нарисованный кодом (пиксельный SVG или canvas в стиле приложения), и показывает скриншоты. Если вы хотите свой рисунок, пришлите макет, и Claude встроит его, как было с меню и городом.

### 0.2 Сквозные тесты в репозитории · M · сделано в 2.1.1

- `tests/e2e/*.spec.ts` на обоих языках: урок слов целиком (все типы заданий, ввод с типографским апострофом), урок грамматики и «Перечитать теорию», повторение, блиц, переключение языка с сохранением прогресса, офлайн, нижнее меню, поздравление с новым уровнем.
- `package.json`: `"e2e": "npm run build && playwright test"`. Vitest не подхватывает `tests/e2e`.
- `pages.yml`: `npx playwright install --with-deps chromium` и `npm run e2e` перед деплоем.

### 0.4 Частотная сверка и план словаря на 3000 слов · M · сделано в 2.2.1

**Зачем.** К финалу нужно не меньше 3000 слов на язык (сейчас 1159). Чтобы 2070 новых слов на язык были полезными, их выбирают по частотности, а не наугад, и заранее распределяют по главам.

**Что меняется.**
- `scripts/data/freq-<язык>.tsv`: 7000 самых частых лемм языка по субтитрам (FrequencyWords, CC BY-SA 4.0), формы сведены к леммам по lemmatization-lists (ODbL). Строит `scripts/build-freq.ts` из скачанных вручную файлов, в приложение не попадает. Рядом `lemmas-<язык>.tsv`: форма → лемма.
- `scripts/vocab-report.ts` (`npm run vocab`): число слов по главам, уровням мест, CEFR и свиткам; повторы лемм между местами; покрытие первых 1000, 3000 и 5000 частотных слов словами мест и грамматикой. Правила подсчёта — в `scripts/vocab-lib.ts`.
- `src/content/vocabPlan.ts`: плановые числа из `GAME.md`. Валидатор печатает «слов: N из плана 3229» по каждому языку и предупреждает, если в уровне места больше плана (12 слов на уровнях 1–4, 30 на 5–6, 25 на 7).
- `docs/vocab/<язык>.md`: частотные слова, которых нет в курсе, по полосам частоты с подсказкой главы. Список для контентных задач 3.9, 4.8, 4.9, 6.1, 6.5, 7.2 и 7.10. Файл пересобирается `npm run vocab`: взятые слова пропадают сами, вручную его не правят. Место или свиток для слова выбирает контентная задача.

### 3.2 FSRS под капотом · M · сделано в 2.13.0

**Нужно до:** 0.3.

**Зачем.** Поручения, медаль «Словесник» и сила Эликсира опираются на то, насколько слово помнится. FSRS даёт это число (стабильность и вероятность вспоминания) и точнее SM-2 планирует повторения.

**Решение.** Библиотека `ts-fsrs`, целевая вероятность 0.9, параметры по умолчанию. `SrsCard` получает `stability`, `difficulty`, `state`, `due` остаётся номером дня. Версия базы 3: `stability` из `interval` (не меньше 1), `difficulty` из `ef` (2.5 → 5, 1.3 → 9), `due` не трогать, чтобы в день обновления не пришла лавина. Оценки: неверно — Again, «почти» — Hard, верно — Good.

**Запрос.**
> Возьми задачу 3.2 из docs/ROADMAP.md. Проверь на старой базе, что в день обновления число карточек к повторению не изменилось.

### 3.3 Устойчивые id упражнений грамматики · S · сделано в 2.13.1

У каждого `GrammarExercise` поле `id` вида `<lessonId>.<n>`, проставленное скриптом `scripts/add-exercise-ids.ts` один раз и не пересчитываемое. Номер — порядок упражнения в файле, с единицы: журнал ответов (0.3) уже пишет упражнения как `g:<lessonId>.<n>` по этому правилу, id должны совпасть. Валидатор проверяет наличие и уникальность.

### 3.4 Правила в повторении · M · сделано в 2.14.0

**Нужно до:** 3.2, 3.3.

После урока грамматики в повторение попадают упражнения с ошибкой и добираются случайные до трёх на урок. Карточки в таблице `cards` с id `g:<exerciseId>`.

**Осторожно.** Экран повторения удаляет карточки, для которых не нашлось слова (`dropCards` в `ReviewScreen`), и счётчики слов считают все карточки. ### 3.5 Поручения жителей · L · сделано в 2.15.0

**Нужно до:** 3.1, 3.4.

## Этап 4. Сюжетные миссии

У каждого жителя по миссии на главу. Миссия — сцена-диалог и ответ героя. Выполненная миссия становится вторым условием обрывка карты.

### 4.1 Фразы мест: схема и проверка · M · сделано в 2.20.0

**Зачем.** Чтобы герой мог отвечать жителям, ему нужны готовые фразы ситуации, а не только отдельные слова.

**Данные.** `src/content/<язык>/phrases/<место>.json`: `{ id, es, ru, level, alt?, note?, grammar? }`, необязательные слова в скобках: `(Yo) quiero un café`. Валидатор: уникальность, длина до 12 слов, покрытие словарём мест того же или более низкого уровня (непокрытое — предупреждение). Образец: по три фразы в кафе на обоих языках.

### 4.2 Фразы мест: контент · L · сделано в 2.21.0–2.24.0

20 мест × 5 уровней × 5 фраз = 500 фраз на язык, пачками по 5 мест, оба языка сразу. Фразы, которые реально говорят в этой ситуации: заказ, просьба, жалоба, вопрос.

**Запрос.**
> Возьми задачу 4.2 из docs/ROADMAP.md, пачка: кафе, рынок, супермаркет, ресторан, дом. После пачки перечитай фразы целиком и исправь неестественные.

### 4.3 Ответ героя своими словами · M · сделано в 2.25.0

**Нужно до:** 4.1.

Проверка ввода фразы в `src/domain/answer.ts`: скобки, `alt`, без ударения и одна опечатка на 8 букв — «почти», пунктуация не важна. Задания: выбор, сборка из плиток с двумя лишними, ввод перевода. Фраза после урока — карточка `p:<id>`, попадает в поручения.

### 4.4 Сцены: схема, валидатор покрытия, экран · L · сделано в 2.26.0

**Данные.** `src/content/<язык>/scenes/<место>.json`: `{ id, chapter, npc, lines: [{ who, es, ru }], questions, gloss? }`. Валидатор: незнакомых слов не больше 7%, отчёт покрытия в `npm run validate`.

**Экран** `/scene/:id`: реплики по одной с озвучкой голосом жителя, перевод слова по нажатию, «Ещё раз», вопросы на понимание.

### 4.5 Движок миссий · M · сделано в 2.27.0

**Нужно до:** 4.3, 4.4.

Миссия = сцена + ветвящийся диалог, где герой отвечает. `src/domain/mission.ts`: граф узлов, реакция жителя на неверный ответ (смешная, но понятная), режим ответа по номеру попытки (1 — выбор, 2 — сборка, 3 и дальше — ввод). Миссия засчитана при 80% верных ответов героя. Условие `mission` для обрывка включается в `chapters.ts`.

### 7.1 Схема выражений C1 · M · сделано в 2.75.0

**Валидатор.** `pair` ссылается на существующее выражение, у пары разный регистр, у идиомы есть `literal`, у ложного друга есть `note`.

**Интерфейс.** В «Моих словах» и на карточке нового слова — метка регистра и пометка для идиом и ложных друзей.

Валидатор: вид только на уровне 7, у выражения обязателен регистр, сочетание, идиома и формула — `pos: 'phrase'`, `literal` только у идиомы и обязателен у неё, `note` так же у ложного друга, `pair` взаимный, ведёт на выражение того же языка с другим регистром. Выражения считаются отдельно от слов уровня: не меньше 10 слов, не больше 15 выражений на место. «Что вы услышали» из двух похожих слов: r/rr, b/v, ударение (papa/papá) в испанском, двойные согласные (pala/palla) в итальянском.

### 10.3 Ответ голосом · M

В миссиях и испытаниях ответ голосом через распознавание речи браузера, только при наличии сети и поддержки, иначе кнопки нет.

### 10.4 Напоминания · M

Время напоминания в настройках. Уведомление через Periodic Background Sync там, где он есть (установленное приложение в Chrome на Android); где нет, честно сказать об этом в настройках.

### 10.5 Праздники · L

Сан-Фермин, Ла Томатина, Феррагосто, Карнавал в Венеции: тематическая неделя со своими словами, миссией, украшением города и тайной медалью.
