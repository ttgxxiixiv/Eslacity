# Eslacity

Приложение: https://ttgxxiixiv.github.io/Eslacity/ (обновляется автоматически при пуше в ветку).

PWA для изучения испанского (A1 → B1) с русского. Город из тематических локаций, интервальное повторение, трек грамматики. Всё хранится на устройстве, бэкенда нет.

```
npm install
npm run dev        # разработка
npm test           # Vitest: проверка ответов, SM-2, очередь урока, валидатор
npm run validate   # проверка контента в src/content
npm run build      # валидация + typecheck + сборка в dist/
```

Контент: 20 локаций по 5 уровней, 1159 слов (уровни 1-2 A1, 3-4 A2, 5 B1), 62 урока грамматики (A1 и A2 по 31). После первой загрузки приложение работает офлайн, ставится на Android через «Добавить на главный экран» (нужен HTTPS).

`npx tsx scripts/make-icons.ts` пересоздаёт иконки в `public/icons`.

Вариант испанского (Испания / Латинская Америка) переключается в `src/config.ts`. План и схемы данных: `docs/PLAN.md`, отчёты по этапам: `docs/STAGES.md`, аудит и список улучшений: `docs/AUDIT.md`.
