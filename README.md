# Eslacity

Приложение: https://ttgxxiixiv.github.io/Eslacity/ (обновляется автоматически при пуше в ветку). APK для Android — по ссылке в настройках приложения.

PWA для изучения языков с русского: испанского (Испания), итальянского, английского (британский), турецкого и португальского (Бразилия). Язык курса выбирается в настройках или с медальона в меню, у каждого языка своя база прогресса. Город из 20 мест, путь через пять земель от A1 до C1, интервальное повторение FSRS, грамматика, миссии, стражи и Сфинкс. После первой загрузки работает без сети, всё хранится на устройстве, сервера нет.

```
npm install
npm run dev        # разработка
npm test           # юнит-тесты (Vitest)
npm run lint       # линтер (oxlint)
npm run validate   # проверка контента всех языков
npm run build      # валидация + typecheck + сборка в dist/
npm run e2e        # сквозные тесты (Playwright)
```

На каждый язык: около 3600 слов и 300 выражений, 132 урока грамматики, 700 фраз, 100 разговоров, 100 миссий, 20 книг для чтения, письма и записки, кузница глаголов, Звонница, два праздника.

Контент лежит в `src/content/<язык>/`, свойства языков — в профилях `src/langs/<язык>/`. Игровой замысел: `docs/GAME.md`, план развития по шагам: `docs/ROADMAP.md`, правила для Claude Code: `CLAUDE.md`. Отчёты по версиям: `docs/STAGES.md`, аудиты: `docs/AUDIT.md`, правила перевода: `docs/TRANSLATION.md`.

Версия: поле `version` в `package.json`. При выпуске поднимите версию и добавьте запись в `src/content/changelog.ts`: её покажет раздел «О приложении».
